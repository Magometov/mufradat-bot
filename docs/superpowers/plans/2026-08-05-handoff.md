## Как владелец просит работать

Это не догадки, а прямые просьбы по ходу первой сессии.

**Этап за этапом с одобрением.** Заканчиваешь кусок — показываешь, что изменилось,
ждёшь ответа. Не берёшь следующий, пока не сказали.

**Коммиты можно, пуш — нет.** `git remote` не настроен ни разу и настраивать его без
отдельного разрешения нельзя, как и пушить куда бы то ни было. Коммитить локально
владелец разрешил. Показывай, чем смотреть: `git status --short`, `git diff`,
`git show <sha>`.

**Не строить того, чем текущий этап не пользуется.** Владелец несколько раз сокращал
модель, и каждый раз был прав. Правило: таблица или поле заводятся тем этапом,
который их использует. Исключение одно — необратимые вещи вроде истории повторов;
про них надо спрашивать отдельно.

**Docstring и комментарии по-русски и коротко.** Идентификаторы английские.
Комментарий пишется там, где объясняет решение, а не пересказывает код. Владелец
регулярно удаляет лишние комментарии — не возвращай их.

**Меньше слоёв.** `pydantic-settings` заменён на `os.getenv`, хелперы в `settings.py`
отвергнуты, модель администратора свёрнута до переменной окружения. Если решение
можно записать строкой — записывай строкой.

**Тесты там, где логика.** На `settings` тестов нет намеренно. Есть на разбор строки
ввода, права, модель, сборку промпта, ответ API.

**Сначала вопрос, потом код — но по одному и просто.** Дважды за сессию владелец
останавливал набор вопросов: первый раз попросил спросить проще, второй — «определись
сам, максимально просто». Правило: спрашивать только там, где ответ меняет работу, и
формулировать бытовым языком, без наших терминов.

**Владелец сам решает, что урезать.** За одну сессию из объёма ушли ФСРС, ИИ и
аутентификация — и каждый раз обоснованно. Если кажется, что решение спорное, надо
сказать это одним абзацем и делать, а не отстаивать написанное.

## Что важно помнить про код

- Запуск с хоста: `uv run python backend/manage.py …`. В Docker только база.
- `pytest` требует `pythonpath = ["backend"]`, он уже в `pyproject.toml`.
- Тесты с асинхронным ORM — только `@pytest.mark.django_db(transaction=True)`,
  иначе записи текут между тестами и проверки «ничего не сохранилось» ложно проходят.
- `ruff` исключает `docs/`: он форматирует python-блоки внутри markdown и портит
  намеренные фрагменты.
- Бот запускается командой `runbot`, живёт долго — в фоне.
- `apps/api` в `INSTALLED_APPS` нет: моделей у него нет, нужен только импорт из
  `config/urls.py`.
- `runserver` в фоне надо убивать по pid, а не через `kill %1`: один раз зависший
  процесс ответил старым кодом, и это чуть не попало в отчёт как результат проверки.
- Редактор владельца может вернуть удалённый файл, если тот открыт во вкладке —
  так однажды воскрес `services/scheduler.py` с опечаткой в первой строке.
- Приложение поднимается `npm --prefix frontend run dev`. Без `--prefix` npm ищет
  `package.json` в корне и падает: в корне его нет и не будет.
- Прод-стек проверять только отдельным проектом compose: `docker compose -p проба -f
  docker-compose.prod.yml`. Имя проекта по умолчанию берётся от каталога, и без `-p`
  прод-описание сервиса `db` пересоздаст рабочий контейнер разработки. `DOMAIN=":80"`
  включает Caddy без https.
- `backend` и `bot` собираются в один образ (`image: mufradat-backend`). Если пересобрать
  только один сервис, второй поедет на старом коде — так и вышло при проверке: бот падал
  на «permission denied», пока исполняемый бит стоял только в свежем образе.
- Бит `+x` на `backend/docker-entrypoint.sh` хранится в git (`100755`). Снимешь — стек
  не поднимется, а сообщение будет про OCI runtime, не про права.
- Расширение Chrome для автоматизации отвалилось на смене размера окна и больше не
  подключилось. Приложение проверялось иначе: `Google Chrome --headless=new
  --remote-debugging-port=9222`, дальше скрипт на node по CDP — клики через
  `Runtime.evaluate`, снимки через `Page.captureScreenshot`. Зависимостей не нужно,
  `WebSocket` в node есть свой. Так же эмулируется тёмная тема
  (`Emulation.setEmulatedMedia`) и размер телефона (`setDeviceMetricsOverride`).
- Тексты обеих сторон карточки всегда лежат в разметке, поэтому `innerText` не
  доказывает, что переворот сработал — это видно только на снимке.
- `$style['ИмяКоторогоНетВСтилях']` молча даёт `undefined`, и класс просто не попадает в
  разметку — ни ошибки, ни предупреждения. Так у лица карточки болталась привязка к
  несуществующему `RunCard__face--front`. Проверять по-настоящему стоящие классы:
  `[...document.querySelectorAll('main *')].map((e) => e.className)`.
- Прогон в `localStorage` лежит как `{ items: [{ id, isReversed }], index }`. Формат уже
  менялся (раньше был список номеров), поэтому `readRun` проверяет форму и старые прогоны
  просто не поднимает.

## Следующий этап: сервер

Конфиги развёртывания готовы и проверены локально — разбор в §14 спеки. Дальше нужны
две вещи, которых у владельца пока нет: **VPS и домен**. Порядок такой: A-запись домена
на сервер, `git pull`, заполнить `.env` (там же `DOMAIN` и `WEBAPP_URL=https://DOMAIN`),
`docker compose -f docker-compose.prod.yml up -d --build`. Кнопка приложения в боте
появится сама, как только `WEBAPP_URL` перестанет быть пустым — это заложено в
`keyboards.open_app`.

Пока сервера нет, приложение смотрят двумя способами. С телефона по локальной сети —
адрес Vite печатает при старте, и это работает без всякой настройки, но мимо Telegram.
Внутри Telegram — только через туннель (`cloudflared`), потому что клиент открывает
Mini App лишь по публичному https. **Туннель без разрешения владельца не поднимать:** он
выставляет машину в интернет.

Разъезд схемы, о котором шла речь весь этап, закрыт с двух сторон: в `vite.config.ts`
стоит `changeOrigin: false` (иначе адрес картинки уходил на `127.0.0.1:8000`, то есть на
сам телефон), а в настройках Django — `SECURE_PROXY_SSL_HEADER`, чтобы за Caddy адрес
собирался с `https`. Проверено подделкой заголовка: с `X-Forwarded-Proto: https` DRF
отдаёт `https://…/m/…`.

**Стиль фронтенда задан глобальными правилами владельца** (`~/.claude/rules/`), и они
подробные: порядок `#region` в `<script setup>`, `withDefaults` обязателен, обращение к
пропсам через `props.x` в шаблоне, CSS Modules и `$style`, rem кратно 0.2, никаких
SCSS-переменных, никакого `backdrop-filter`. Читать до первой строки кода, а не после.

## Мелочи, которые стоит закрыть

- Токен бота светился в выводе терминала при отладке — стоит перевыпустить через
  `/revoke` у @BotFather.
- В `.env` остались строки `ANTHROPIC_API_KEY` и `AI_MODEL`. Их больше никто не читает,
  из `settings.py` и `.env.example` они убраны; в самом `.env` не трогали, это файл
  владельца.
- В конце прогона тестов остаётся предупреждение об удалении тестовой базы: открытое
  асинхронное соединение. Косметика, лечится закрытием соединения только для
  асинхронных тестов.
